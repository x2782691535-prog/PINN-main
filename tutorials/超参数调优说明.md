# PI-ATCNN 超参数调优指南

## 📋 概述

`BCI_IV_2a_classification_V4_HyperOpt.py` 是一个自动化超参数搜索脚本，帮助你找到最佳的模型参数组合。

## 🔍 搜索的超参数

| 参数 | 搜索范围 | 说明 |
|------|---------|------|
| **dropout_rate** | [0.3, 0.4, 0.5] | Dropout正则化强度 |
| **init_physics_weight** | [0.1, 0.15, 0.2, 0.25, 0.3] | 物理损失初始权重 |
| **learning_rate** | [0.0005, 0.001, 0.002] | 学习率 |
| **batch_size** | [16, 32, 64] | 批次大小 |
| **weight_decay** | [1e-4, 2e-4, 3e-4, 5e-4] | L2正则化强度 |
| **repeat_factor** | [2, 3, 4] | 数据增强倍数 |

## 🚀 运行方法

### 方法1: 随机搜索（推荐，快速）

```bash
python tutorials/BCI_IV_2a_classification_V4_HyperOpt.py
```

**特点**：
- ✅ 随机采样30组参数组合
- ✅ 快速探索参数空间
- ✅ 约需要2-4小时（取决于GPU）
- ✅ 适合初步调优

### 方法2: 网格搜索（全面，耗时）

修改脚本最后部分：

```python
# 将这一行改为 'grid'
best_result, all_results = hyperparameter_search(
    search_type='grid'  # 改为 'grid'
)
```

**特点**：
- 📊 测试所有参数组合
- 📊 总共 3×5×3×3×4×3 = **1620组** 组合
- ⏰ 可能需要数天时间
- 💡 建议在随机搜索后，缩小范围再用网格搜索

## 🎯 评分标准

脚本使用综合评分选择最佳参数：

```
综合得分 = 验证准确率 - 0.3 × max(0, 过拟合间隔)
```

这样既考虑了准确率，又惩罚了过拟合。

## 📈 结果分析

### 查看所有结果排名

```python
import json

# 读取结果文件
with open('hyperparameter_search_results_20241024_120000.json', 'r') as f:
    data = json.load(f)

# 按验证准确率排序
results = data['all_results']
sorted_results = sorted(results, 
                       key=lambda x: x['metrics']['val_accuracy'], 
                       reverse=True)

# 打印前10名
for i, result in enumerate(sorted_results[:10]):
    print(f"\n排名 {i+1}:")
    print(f"  参数: {result['params']}")
    print(f"  验证准确率: {result['metrics']['val_accuracy']:.2f}%")
    print(f"  测试准确率: {result['metrics']['test_accuracy']:.2f}%")
```

### 可视化结果

```python
import matplotlib.pyplot as plt
```

## ⚠️ 注意事项

1. **GPU内存**: 网格搜索需要较大GPU内存，如果遇到OOM错误，减小batch_size范围

2. **早停机制**: 脚本使用较少的epoch(100)和较小的patience(25)进行快速评估

3. **数据集**: 当前使用S1进行快速评估，最终参数应在所有受试者上验证

4. **随机性**: 由于数据增强的随机性，建议对最佳参数重复运行3次取平均

5. **过拟合权衡**: 评分公式会惩罚过拟合，如果只关心测试准确率，可以修改评分标准
