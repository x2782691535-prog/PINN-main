# BCI-IV-2a源定位分析系统 - GUI使用说明

## 概述
这是一个基于ESINet深度学习框架的BCI-IV-2a源定位分析图形用户界面系统。用户可以通过友好的界面完成从数据导入到结果分析的整个源定位流程。

## 启动方法
```bash
cd tutorials
python BCIIV2a_GUI.py
```

## 界面说明

### 第一页面：数据准备
**功能：**
- 导入真实的BCI-IV-2a EEG数据
- 生成模拟数据用于测试和训练
- 设置模拟参数
- 可视化EEG信号和3D脑源分布

**操作步骤：**
1. 点击"导入EEG数据"选择BCI-IV-2a数据文件夹，或点击"生成模拟数据"创建测试数据
2. 调整模拟参数（如果使用模拟数据）：
   - 试验持续时间：控制每个试验的时长
   - 目标信噪比：控制数据的噪声水平
   - 源数量：设置脑源的数量
   - 源范围：控制源的空间扩展范围
   - Beta参数：控制源活动的强度参数
3. 点击"应用参数并生成数据"更新模拟数据
4. 在右侧查看EEG信号波形和3D脑图

### 第二页面：网络训练
**功能：**
- 设置训练参数
- 启动网络训练
- 实时监控训练状态
- 可视化训练Loss曲线

**操作步骤：**
1. 确保已在第一页面准备好数据
2. 调整训练参数：
   - 学习率：控制网络学习的步长
   - 批大小：每次训练使用的样本数量
   - 训练轮数：最大训练轮数
   - 早停耐心值：防止过拟合的早停机制
3. 点击"开始训练"启动训练过程
4. 在右侧观察实时的Loss曲线变化
5. 训练完成后查看最终的Loss曲线

### 第三页面：结果可视化
**功能：**
- 计算评估指标（MLE、MSE、AUC）
- 显示预测结果和真实分布的3D脑图
- 保存结果和图像

**操作步骤：**
1. 确保已完成网络训练
2. 点击"计算评估指标"生成测试数据并计算性能指标
3. 查看左侧显示的评估结果：
   - 定位误差(MLE)：平均定位误差，越小越好
   - 均方误差(MSE)：预测与真实值的差异，越小越好
   - AUC值：分类性能指标，越接近1越好
4. 点击"显示预测结果"或"显示真实分布"查看3D脑图
5. 点击"保存3D图像"保存脑图截图
6. 点击"保存结果"保存完整的分析报告

## 技术特性

### GPU支持
- 系统自动检测GPU设备
- 支持GPU加速训练，大幅提升训练速度
- 如无GPU设备，自动切换到CPU训练

### 多线程训练
- 训练过程在后台线程中进行
- 避免训练时界面卡死
- 可随时停止训练过程

### 交互式可视化
- 高质量的EEG信号波形图
- 交互式的Loss曲线显示
- 支持多视角的3D脑源分布可视化

### 完整的保存功能
- 支持保存训练参数
- 支持保存评估结果
- 支持保存3D脑图截图

## 注意事项
1. 首次运行时，系统会自动下载MNE样本数据，请确保网络连接
2. 3D脑图会在新窗口中显示，可能需要安装PyVista相关依赖
3. 建议在有GPU的环境中运行以获得最佳性能
4. 确保有足够的内存空间用于数据处理和模型训练

## 系统要求
- Python 3.7+
- MNE-Python
- ESINet
- TensorFlow 2.x
- PyVista（用于3D可视化）
- Tkinter（通常随Python安装）

## 故障排除
如果遇到问题，请检查：
1. 是否安装了所有必要的依赖包
2. MNE样本数据是否正确下载
3. 对于3D可视化问题，请确保PyVista正确安装
4. 检查控制台输出的错误信息
