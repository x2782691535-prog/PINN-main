# Localize-MI
## Simultaneous human intracerebral stimulation and HD-EEG: ground-truth for source localization methods

The dataset comprises high density-EEG data from a total of 61 sessions, obtained from 7 subjects. In addition, it includes the spatial locations of the stimulating contacts in native MRI-space, MNI152-space and Freesurfer’s surface-space, and the digitized positions of the 256 scalp EEG electrodes. It also contains the BEM, pial and inflated surface reconstructions created with the subjects’ original MRIs, as well as the source-spaces and forward-models from them derived. Furthermore, it includes the anonymized MRIs of each subject.

The code used for data curation, analysis and utility functions, as well as usage demonstration scripts can be found in the following repository:

https://github.com/iTCf/mikulan_et_al_2020
